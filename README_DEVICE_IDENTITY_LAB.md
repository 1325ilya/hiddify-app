# Device Identity Lab — Раздел разработчика в Hiddify iOS

Мы успешно добавили безопасный, премиальный инструмент дебага и аудита **Device Identity Lab** в раздел разработчика настроек Hiddify.

---

## Что добавлено

1. **Нативная Swift-интеграция**:
   - Нативный класс `DeviceIdentityMethodHandler` в `ios/Runner/Handlers/PlatformMethodHandler.swift`.
   - Безопасное хранение `App Instance ID` в **Keychain** (хранилище сохраняется при переустановке приложения).
   - persistent `Install UUID` в UserDefaults (для отслеживания сессии установки).
   - Определение поддержки App Attest / DeviceCheck.
   - Сбор Bundle ID, сборки, версии и параметров `UIDevice` (модель, версия системы, имя устройства).

2. **Модуль диагностики (Dart/Flutter)**:
   - Автоматический перехватчик HTTP-запросов `RequestDiagnosticsInterceptor`, встроенный во все клиенты `DioHttpClient`.
   - Внутренний логгер-хранилище `RequestDiagnosticsStore` последних 50 запросов.
   - Маскировщик конфиденциальных данных `maskUrl` и `maskHeaders` (скрывает ключи, токены авторизации, пароли, UUID в URL и заголовках).

3. **Тестовое переопределение (Test Identity Override)**:
   - Возможность переопределения IDFV, модели устройства и Keychain Instance ID.
   - **Переключатель `allowAllDomains` (Отправлять всем провайдерам)**: позволяет отправлять измененный User-Agent (например, `HAPP` вместо `Hiddify`) и custom HWID абсолютно ко всем провайдерам и хостам.
   - Доменный Allowlist: если `allowAllDomains` выключен, подмена применяется только к разрешенным staging/local хостам (например, `localhost`, `127.0.0.1`, `*.local`), исключая продакшн-сервисы во избежание сбоев.

4. **Премиальный UI**:
   - Раздел **Settings -> Developer Tools -> Device Identity Lab**.
   - Современные градиенты, карточки с копированием значений в один клик.
   - Интерактивный лог исходящих запросов с цветовыми индикаторами активности переопределения.
   - Кнопка очистки логов и экспорт безопасного маскированного отчета в формате JSON (Share / Поделиться).

---

## Где включить и как использовать

1. Перейдите в **Settings** (Настройки).
2. Нажмите на плитку **Developer Tools** (Инструменты разработчика).
3. Откройте раздел **Device Identity Lab**.
4. Включите переключатель **Enable Test Identity Override** (Включить тестовое переопределение).
5. Настройте параметры:
   - Введите кастомный **Test Device ID** (IDFV), **Test Model** (Модель) или **Test App Instance ID** (HWID).
   - В поле **Custom Client Name** укажите нужное имя клиента (например, `HAPP`).
6. Включите **Allow All Domains** (Отправлять всем провайдерам), чтобы измененный `User-Agent` (например, `HAPP/4.1.2 (iOS) like ClashMeta ...`) и HWID-заголовки (`X-HAPP-Hardware-ID`) отправлялись при всех запросах ко всем провайдерам.
7. Или добавьте ваш staging домен в **Allowed Overrides Domains Allowlist** ниже, чтобы ограничить область тестирования.
8. Сделайте запрос (например, обновите подписку). Спуститесь вниз экрана «Device Identity Lab» к разделу **Request Diagnostics Logs** и раскройте детали запроса, чтобы увидеть, какие заголовки ушли провайдеру.

## Безопасность и легальность
- **Конфиденциальность**: Логи хранятся только локально в оперативной памяти и никуда не загружаются. Все sensitive поля (авторизация, токены) автоматически маскируются (`abc...xyz`).
- **Legal**: Инструмент не вмешивается в системные iOS identifiers на уровне ОС и не обходит SSL pinning или HTTPS-трафик сторонних приложений.

## Тестирование

### Запуск автоматических юнит-тестов
Запустите в терминале:
```bash
flutter test test/features/device_identity_test.dart
```

Все тесты проверяют корректность маскирования токенов в URL и заголовках, а также категоризацию запросов.

## Сборка неподписанного IPA через GitHub Actions

Так как сборка iOS-приложений требует операционной системы macOS и Xcode, мы добавили автоматический workflow для сборки неподписанного IPA-файла без необходимости наличия платного аккаунта разработчика Apple.

### Инструкция по запуску:
1. Закоммитьте и отправьте (push) текущий локальный код в ваш форк/репозиторий на GitHub:
   ```bash
   git add .
   git commit -m "feat: add Device Identity Lab & build unsigned iOS workflow"
   git push origin main
   ```
2. Откройте страницу вашего репозитория на GitHub.
3. Перейдите во вкладку **Actions**.
4. В левой боковой панели выберите рабочий процесс **Build Unsigned iOS IPA**.
5. Нажмите на выпадающий список **Run workflow** справа и нажмите кнопку **Run workflow** (запустить).
6. После успешного завершения сборки (около 5-8 минут) кликните на завершенный ран сборки.
7. Прокрутите страницу вниз до раздела **Artifacts** (Артефакты) и нажмите на архив **hiddify-unsigned-ios-ipa**, чтобы скачать готовый неподписанный `.ipa` файл!

Этот `.ipa` можно установить на ваше устройство с помощью **TrollStore, AltStore, Sideloadly, TrollLauncher** или использовать на jailbreak-устройстве.
